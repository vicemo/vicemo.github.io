Fuzzy Homologation Platform

Pharmaceutical product data standardization · C# / ASP.NET MVC

C# .NET / ASP.NET MVC SQL Server IIS Windows Authentication (SSO) Jaro-Winkler Soundex

Developed an enterprise platform in C# / ASP.NET MVC to automate the homologation and selection of pharmaceutical products from different data sources. Implemented fuzzy matching techniques using Jaro-Winkler and Soundex to identify potential product matches and generate automatic recommendations, while allowing non-technical users to review, select, and approve homologations through a simple interface.

The platform included automated and manual matching workflows, homologated-record management, SSO authentication, and role-based access control — significantly simplifying the product-mapping and data-quality process for pharmaceutical market data across Central America and the Dominican Republic.

Matching workflow

The core of the platform is a two-track matching engine: an automatic pass that scores candidate products using Jaro-Winkler string similarity and Soundex phonetic matching, and a manual review track for the cases the engine flags as uncertain. Approved matches move into a homologated-records store; unresolved records are kept visible so nothing silently falls through the cracks.

Admin & security

Access is gated by Windows Authentication (SSO) at the IIS level, with role-based permissions inside the app itself — so reviewers, approvers, and administrators each see only the actions relevant to their role.

Architecture

The application is hosted on IIS with Windows Authentication handling SSO, and SQL Server as the backing store for both product data and homologation records. The backend is built in ASP.NET MVC, keeping the fuzzy-matching logic, workflow state, and access control on the server rather than exposing raw database access to end users.
